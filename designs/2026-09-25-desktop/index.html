Busta for desktop

A small desktop app for Linux, macOS and Windows: Busta in its own window, plus what a browser tab can't do. It adds a tray (menu bar) icon with your unread count and newest mail, native notifications for folders you choose, Busta as your default mail app (mailto: links), keyboard shortcuts, and launch at login. v2: a real client, not a browser tab. The app runs Busta's own Astro pages inside the app (Electron, Node built in) and gets your mail from Busta over Cap'n Web, Cloudflare's RPC, on one WebSocket. Your mail stays in the cloud; the app holds only what's on screen and a revocable token. Every page you use on the web renders the same here, and changes arrive live. The mail shown is example data; the folders and accounts are yours.

Electron, so the app runs Busta's own pages

Electron has Node built in, so the app runs Busta's Astro pages itself, the same ones busta.app serves, built for Node instead of Workers. One UI, two builds: every web feature lands on the desktop with no extra UI work, and it renders identically on all three systems. The cost is size (~150 MB, versus ~10 MB for Tauri, which would need a second UI written from scratch). The trade: because the pages ship inside the app, a new web feature reaches the desktop with the next app update (downloaded quietly, applied on restart), not the moment it deploys. The app checks its version against /rpc and asks to restart if it falls too far behind.

Connect this computer, once

The app opens your normal browser to Busta, where you're already signed in, and asks "Connect Jesse's ThinkPad?". Approving sends a one-time code back to the app (to 127.0.0.1 only), which trades it for a desktop token for your user and org. It lasts 90 days and renews while you use it, and you can revoke it from any browser under Accounts → Your computers.

Notifications are opt-in, like texting

Off until you turn them on in Preferences. You pick the folders (none are picked for you). By default a notification says "New email in Bank"; sender and subject are a separate opt-in, because a desktop notification can show on a locked or shared screen. Security mail (codes, resets) never notifies.

The tray keeps it one click away

The icon sits where each system puts them: the top bar on Linux, the menu bar on macOS, the system tray by the clock on Windows. It shows your unread count across the accounts you show. Clicking it lists your 6 newest in Messages, plus Compose, Open Busta and "Pause notifications for 1 hour". Closing the window keeps Busta in the tray, so notifications keep coming; Quit really quits.

Needs a yes

Linux, macOS and Windows at launch

Linux (AppImage and .deb), macOS (.dmg for Apple silicon and Intel) and Windows (.msi), all built by one GitHub Actions workflow on each tag. Signing is what costs: macOS needs an Apple Developer account ($99/year) to sign and notarize, and Windows needs a code-signing certificate (Azure Trusted Signing, about $10/month) or SmartScreen warns on install. Installs and signed updates come from GitHub Releases on jtaylorcpp/busta.

Your mail stays in the cloud

The app gets mail from Busta over Cap'n Web on one WebSocket: authenticate(token) returns your session, and only what your org owns can be reached from it. Nothing is written to disk but a desktop token, kept in the system keychain and revocable from the web. Links in an email open in your normal browser.

Offline is honest

Without a connection the window keeps what's on screen, the title bar says "Reconnecting…", and actions wait: a reply stays a draft in the cloud, nothing pretends to send. It reconnects by itself and catches up. A local copy of your mail (true offline) is deliberately out of scope.
