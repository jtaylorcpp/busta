Search, Drafts and Compose

These three pages go to Astro next. They use the approved palette and the same shell as Mailbox and Thread, and they only show what the backend already does: cursor-based search with filters, saved drafts, and one compose form for new mail, forwards and draft edits.

Search loads as you scroll

The first 25 results are rendered on the server. A small island loads the next slice when the list end comes into view, with a Load more button as a fallback. Without JavaScript the button is a plain link. There are no page numbers because the index is walked newest to oldest with a cursor and has no total.

Scanned vs shown

Each request scans a bounded window of the mailbox. A window can find nothing and still not be the end, so the island says so and keeps going instead of reporting "no results".

Matches are highlighted

The query term is marked in amber in subjects and snippets. Amber here is a highlight, not a state; if that reads as "in flight", we can switch it to the primary tint.

One compose form

New, Forward and Edit draft are the same page. Forward pre-checks the original's attachments; Edit draft shows files already saved with it. Send, Save draft and Discard are the only actions.

Large files become links

Files over the inline limit are marked "link · 30 days" in amber before sending, so the sender knows the recipient gets a download link instead of an attachment.

Errors name the recipient

A refused send keeps the form, turns the offending address chip crimson, and says what to do: remove it and try again.
