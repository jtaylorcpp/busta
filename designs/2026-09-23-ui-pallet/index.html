Busta theme

Busta's mail client drops the Windows 95 look for a quiet, Gmail-style layout: white reading surfaces on a cool grey ground, one blue for actions, and red reserved for what needs you. Every role has a light and a dark value, and every text color below passes WCAG AA against the surfaces it sits on.

Decided: red stays on unread. Attention and error are kept apart by hue and by form. Attention is a brighter vermilion used only as small marks (the unread dot, counts, bold dates). Error is a deeper crimson that always comes as a tinted banner or chip with an icon and words.

03 · Rules

How the roles are used

Red means "look at this"

Attention red only marks unread mail and unread counts. It never fills a large area, so a glance down the list finds new mail instantly.

Errors always carry words

Bounces, failed sends and invalid fields use crimson with a tint, an icon and a sentence saying what went wrong. Color alone never carries the message.

Violet is the agent

Tertiary is reserved for the mail agent: the agent bar, agent-drafted replies, "Ask agent". You can always tell what the agent touched.

Unread rows are brighter

Unread rows sit on the full surface in bold; read rows drop onto the shaded surface. Dark mode keeps the same logic with lifted surfaces.

Amber is in-flight

Warn covers anything waiting: queued delivery, retry, drafts held for review, setup steps. Nothing has failed yet.

One blue for actions

Compose, Send, links, the focus ring and the selected folder. Secondary slate handles +tags and quiet buttons so blue stays meaningful.

Caution is amber, failure is crimson

A message whose place in the thread can't be verified gets a dashed amber border and a plain explanation. Nothing has failed yet, so it isn't an error; crimson stays for bounces and failed sends.

Audience changes get a divider

When To, Cc or Bcc changes mid-thread, a line spans the conversation right before the message that changed it, naming who did it and each address added, removed or moved. Bcc changes show only to the sender.
