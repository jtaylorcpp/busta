Getting Started

A new mailbox opens on a short guide instead of an empty list. It teaches how Busta works by doing it once: you describe what matters to you in a sentence or two, Busta makes a Must read folder from it, and you send yourself a message to watch it get filed. Three steps, a couple of minutes, and you've used every part of folders and rules.

When it shows

On Messages, for a mailbox that hasn't finished or dismissed the guide. It sits above the list, so mail that arrives meanwhile is still visible. Progress is saved per mailbox, and Getting started in the account menu reopens it any time.

Must read is a normal folder

The guide only pre-fills the name and prompts for the rule. After that it behaves like any other folder: rename it, edit the sentence, delete it. Folders you made before the guide aren't touched, and if one is already called Must read, the guide edits that one.

Testing before there's mail

A new mailbox is empty, so "Test this rule" runs on eight built-in sample messages, marked Sample. It's the same typesafe/jev call a real message gets, so what you see is how the rule will really behave. When you have mail, the test uses yours instead.

The live test

Step 3 waits on the mailbox's existing WebSocket. When a message arrives, it slides in and the step completes on its own, whether or not it went into Must read. If it didn't, the guide explains what that means and offers to edit the rule. Nothing is sent for you.

Colors keep their meaning

Blue marks the current step, green only completed steps and "It worked", and amber means waiting (the same as Sorting…). The red dot stays for unread mail only. Sample uses the warn tint so examples never pass for your own mail.

Skipping

Each step can be skipped, and "Hide guide" closes it. Skipping the rule step creates no folder. The guide never blocks reading mail.
